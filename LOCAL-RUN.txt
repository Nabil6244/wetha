Weather Intelligence Studio — local development quick start

This download contains Phase 5 source code, not a standalone installer.
Install Node.js 24 and Python 3.12, then extract this ZIP into Downloads.
Open a terminal in the extracted wetha folder.

Windows PowerShell:
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --require-hashes -r backend/requirements.lock
npm ci
npm run dev

macOS / Linux:
python3.12 -m venv .venv
.venv/bin/python -m pip install --require-hashes -r backend/requirements.lock
npm ci
npm run dev

Stop if any setup command fails and share its error. Keep the terminal open.
For browser mode, open http://127.0.0.1:5173 in your local browser.
For the Electron desktop app, stop dev with Ctrl+C and run npm run desktop.
Never disable the Electron sandbox to bypass a launch failure.

Your database starts fresh. Click Refresh sources to collect official weather
records, or Load training dataset for clearly labeled synthetic practice data.
Visual Director includes maps, satellite/radar observation collection and
revision-bound scene plans. Install FFmpeg/FFprobe for Media Library imports
and Video Production. In Create Video, paste your finished script and click
Save script & prepare automatically. Upload its matching voiceover, then
click Make final video. Source checks, spoken timing and the mixed edit
run automatically. Audio matches below 95% need confirmation. Preview and download the MP4 under Your
videos. Edit visuals & timing opens the detailed editor. No local voiceover
is generated.
Network access is required for dependencies and live weather. NHC cone
requests may return HTTP 403. Broadcasting is a future phase.
